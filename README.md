# TempoJusto

**TempoJusto** é um projeto acadêmico de Usabilidade, Design de Interação e Acessibilidade Digital.

A proposta é criar um banco comunitário de tempo: **1 hora de contribuição = 1 Crédito-Hora**. Os Créditos-Hora circulam entre pessoas diferentes e representam tempo compartilhado, não dinheiro, investimento, fintech ou criptomoeda.

## Fase atual

O projeto entrou temporariamente na fase de **ideação, documentação e apresentação ampla** antes da continuação do desenvolvimento do site.

Já existe um protótipo navegável inicial em Lovable, mas o repositório público será usado primeiro para organizar:

- visão do projeto;
- problema e justificativa;
- público-alvo e personas;
- funcionamento do banco de tempo;
- regras de confiança e segurança;
- requisitos de acessibilidade;
- roteiro da apresentação;
- roadmap do MVP.

## Ideia central

> Seu tempo também tem valor.

O TempoJusto conecta pessoas que podem oferecer uma hora de ajuda com pessoas que precisam receber uma hora de apoio. A troca é registrada como Crédito-Hora apenas após confirmação das duas partes.

## Escopo inicial previsto

- Home pública;
- exploração de habilidades;
- detalhe de serviço;
- cadastro/login;
- perfil do usuário;
- oferta de habilidade;
- solicitação de troca;
- acompanhamento de status;
- carteira de tempo;
- avaliações bidirecionais;
- regras de convivência;
- acessibilidade desde a arquitetura.

## Princípios

1. Uma hora vale uma hora.
2. Créditos-Hora não são dinheiro.
3. Dados sensíveis não devem ser expostos.
4. Acessibilidade não é extra, é requisito.
5. A confiança depende de confirmação, avaliação, denúncia e bloqueio.
6. A tecnologia deve reforçar comunidade, não transformar a ideia em banco ou marketplace agressivo.
